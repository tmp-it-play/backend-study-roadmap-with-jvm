# Spring Boot 백엔드 로드맵

Java와 Kotlin을 바탕으로 Spring Boot, 데이터베이스, 테스트와 운영을 배우는 한국어 백엔드 로드맵입니다.

단원 본문을 열면 자동으로 학습 완료가 표시됩니다. 예제와 실습을 함께 확인하세요. 진도는 현재 브라우저에 저장되며 완료 표시는 직접 바꿀 수 있습니다.

코드 실습은 [실습 시작하기](examples/README.md)를 참고하세요.

## 내 컴퓨터에서 보기

Node.js 22 이상에서 실행합니다.

```sh
npm ci
npm run dev
```

브라우저에서 [로드맵 열기](http://127.0.0.1:3000).

[Nest 백엔드 로드맵](https://github.com/tmp-it-play/backend-study-roadmap-with-nest/tree/246353e98b5db66b004fc7e5e0cc34449078c768)의 학습 방식과 SVG 일러스트 코드를 참고했습니다.
