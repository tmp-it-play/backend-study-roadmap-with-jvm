# JVM 로드맵 화면 설계

참고 저장소는 [backend-study-roadmap-with-nest](https://github.com/tmp-it-play/backend-study-roadmap-with-nest/tree/246353e98b5db66b004fc7e5e0cc34449078c768)입니다. 밝은 하늘과 도시, 초록 표지판, 지그재그 도로가 학습 순서를 표현합니다. 원본 소스를 로컬에서 실행해 화면과 문서 탐색 방식을 확인했습니다.

## 시각 언어

| 용도 | 색상 | 적용 |
| --- | --- | --- |
| 하늘 | #5ec2ec | 첫 화면과 단계 소개 |
| 표지판 | #0e6a33 | 단계 제목과 주요 탐색 |
| 짙은 초록 | #094d24 | 상단 바와 본문 강조 |
| 잔디 | #6da43b | 도로 주변 배경 |
| 안내 노랑 | #ffd43b | 현재 위치와 주요 버튼 |
| 본문 종이 | #ffffff | 상세 목차와 보충 설명 |

- 제목은 Do Hyeon, 본문은 Noto Sans KR을 사용합니다. 폰트는 패키지에서 로컬 제공해 빌드 시 외부 폰트 요청이 필요하지 않게 합니다.
- 홈은 가운데 정렬한 도로 표지판과 좌우 교차하는 단계 목록으로 구성합니다. 상세 화면은 읽기 편한 왼쪽 정렬과 제한된 본문 폭을 사용합니다.
- 도로와 표지판을 기억할 시각 요소로 삼고, 별도의 장식용 이미지나 반복적인 등장 애니메이션은 추가하지 않습니다.
- 원본의 SVG 도시·자동차 일러스트 생성기를 출처를 남겨 활용합니다. 콘텐츠·탐색·상태 코드는 JVM 과정에 맞게 작성합니다.
- 원본의 도로 비유를 유지하되 흰 글씨가 잔디에 묻히지 않도록 설명은 진한 글씨나 흰 본문 영역에 배치합니다.

## 화면 구조

```text
상단  JVM 로드맵                         전체 목차  보충 지식
좌측  학습 단계             본문  하늘과 도시
      01 개발 환경                JVM 백엔드 학습 / 로드맵 표지판
      02 Java                     이어 학습하기와 전체 진행률
      03 Kotlin                   도로 보기 / 목록 보기 / 검색
      …                           좌우로 이어지는 16개 구간

상세  단계 소개 → 세부 목차 → 실습 산출물 → 완료 기준
      관련 보충 설명 → 공식 출처 → 이전 단계 / 다음 단계
```

## 동작

- 검색은 단계 제목, 학습 단위와 세부 주제, 보충 설명을 찾습니다. 빈 결과에 검색 초기화를 제공합니다.
- 학습 완료는 세부 학습 단위별로 브라우저에 저장합니다. 기본과 선택 심화의 진행률을 구분합니다.
- 단계 링크는 각 학습 단위의 앵커로 이동합니다. 실제 본문이 집필되기 전에는 상세 목차라는 사실을 명확히 표시합니다.
- 보충 지식은 관련 단계와 별도 색인에서 같은 데이터를 표시합니다. DSL과 언어 비교 예제는 탭으로 전환합니다.
- 좁은 화면은 접이식 메뉴와 한 열 레이아웃을 사용합니다. 키보드 포커스, 레이블, reduced-motion을 지원합니다.

## 이번 구현 범위

전체 커리큘럼, 단계별 상세 목차, 보충 설명 32개, 실습·완료 기준, 검색, 진도 저장, 목록·도로 전환, 반응형 탐색을 구현합니다. 110개 학습 단위의 전체 강의 본문과 Spring 실행 예제, 시뮬레이터는 이 설계를 바탕으로 후속 집필합니다.
